## Activos de SecureShop

**Tipos de clasificación:** Información · Software · Servicio · Infraestructura · Datos

| # | Activo | Tipo | Consecuencia |
|---|--------|------|--------------|
| 1 | Información de usuarios | Información | Accedido: Fuga de datos personales, sanciones legales y pérdida de confianza de los clientes<br>Modificado: Datos erróneos de contacto; pedidos enviados a direcciones equivocadas<br>Indisponible: Los clientes no pueden ver ni actualizar su perfil |
| 2 | Credenciales | Información | Accedido: Suplantación de identidad y compras fraudulentas a nombre de otros<br>Modificado: Bloqueo de cuentas legítimas o toma de control por un atacante<br>Indisponible: Nadie puede iniciar sesión; el sistema queda inutilizable |
| 3 | Catálogo de productos | Datos | Accedido: Competidores conocen precios y stock (impacto bajo, es información mayormente pública)<br>Modificado: Precios alterados que causan pérdidas económicas o ventas a valores incorrectos<br>Indisponible: Los clientes no pueden ver productos y no se realizan ventas |
| 4 | Registro de pedidos | Datos | Accedido: Exposición de hábitos de compra, montos y direcciones de clientes<br>Modificado: Pedidos alterados, cancelados o con montos falsos; conflictos con clientes<br>Indisponible: No se pueden consultar ni dar seguimiento a los pedidos |
| 5 | API Gateway | Servicio | Accedido: Un atacante descubre las rutas internas y la estructura de los microservicios<br>Modificado: Redirección de solicitudes a servicios maliciosos o evasión de controles de acceso<br>Indisponible: Todo el sistema cae, porque es el único punto de entrada |
| 6 | User Service | Software | Accedido: Consulta y listado masivo de usuarios sin autorización<br>Modificado: Creación de usuarios falsos o cambio de roles (escalamiento de privilegios)<br>Indisponible: No se pueden registrar ni autenticar usuarios |
| 7 | Product Service | Software | Accedido: Acceso a funciones administrativas del catálogo<br>Modificado: Actualización no autorizada de productos, precios o stock<br>Indisponible: El catálogo no carga y se detienen las ventas |
| 8 | Order Service | Software | Accedido: Consulta de pedidos de otros clientes<br>Modificado: Pedidos manipulados o creados sin pago<br>Indisponible: No se pueden crear pedidos; pérdida directa de ingresos |
| 9 | Bases de datos por dominio | Infraestructura | Accedido: Robo completo de la información de usuarios, productos y pedidos<br>Modificado: Corrupción o eliminación de registros de todo un dominio<br>Indisponible: El microservicio correspondiente deja de funcionar |
| 10 | Código fuente | Software | Accedido: Atacantes descubren vulnerabilidades o secretos expuestos en el código<br>Modificado: Inserción de código malicioso (puertas traseras) en la plataforma<br>Indisponible: No se pueden desplegar correcciones ni nuevas versiones |
